## Implementation Details

### PrintifyAdapter
- Auth: Bearer token (Authorization: Bearer ***) - per docs/09 §2.3
- Rate limit: 600 req/min firm cap (R5) → bucket 8 req/s, burst 20
- Webhook: X-Printify-Signature HMAC-SHA256
- Endpoints: POST /v1/shops/{id}/products, PUT /v1/shops/{id}/products/{id}, GET /v1/shops/{id}/orders, GET /v1/shops/{id}/products/{id}
- POD model: No direct file upload, blueprint/variant configuration

### GelatoAdapter
- Auth: X-API-KEY header + optional OAuth2 - per docs/09 §2.4
- Rate limit: Conservative 4 req/s + jittered backoff (UNVERIFIED public cap)
- Webhook: X-Gelato-Signature HMAC-SHA256
- Endpoints: POST /v1/products, PATCH /v1/products/{id}, GET /v1/orders, GET /v1/products/{id}
- Global production: 140+ hubs in 32 countries

### Common Infrastructure (per docs/11-architecture.md §4)
- Shared HTTP client (reqwest w/ rustls ≥0.23.45)
- Shared TokenBucket (tower Layer) via RateLimiter
- Shared RetryPolicy (exp backoff + jitter, max 5 attempts, only on 429/5xx)
- Constant-time HMAC verification via `subtle::ConstantTimeEq` + `ring::hmac`
